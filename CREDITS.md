# Credits

Design patterns ported from two MIT-licensed open-source portfolios. The code here is my own rewrite in plain CSS and JS; the ideas and proportions come from theirs.

- bchiang7/v4 (MIT, Brittany Chiang), 8.3k stars: numbered section heading with a trailing hairline, inline link underline that grows on hover, outlined button with a hard offset shadow, fixed side rails (social icons left, vertical email right, each ending in a thin line), dashed focus ring and thin scrollbar. https://github.com/bchiang7/v4
- Naresh-Khatri/3d-portfolio (MIT, Naresh Khatri), 1.3k stars: the preloader that counts up and slides out with the (.76, 0, .24, 1) curve. (Version 2 also used its Lenis setup and BoxReveal; version 3 uses native scrolling and dropped both.) https://github.com/Naresh-Khatri/3d-portfolio
- Flexoki (MIT, Steph Ango): the colour palette. Dark: base-950, base-900, base-50, base-200, base-500, orange-400, cyan-400. Light: paper, base-50, base-950, base-800, base-600, orange-600, cyan-600. https://github.com/kepano/flexoki
- visual-lesson-builder: the interactive GPU lesson engine (lesson/gpu.html).
- Libraries: three.js 0.160.0 (MIT). Version 3 loads no other script library.

MIT license text of the two portfolios: https://github.com/bchiang7/v4/blob/main/LICENSE and https://github.com/Naresh-Khatri/3d-portfolio/blob/main/LICENSE
